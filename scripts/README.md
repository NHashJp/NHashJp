# Regenerating the SVGs

The animated SVGs in `../assets` are generated by these scripts. All text is converted
to vector outlines, so the images look identical everywhere and load no fonts. That
matters because GitHub's image sandbox blocks font loading.

```bash
cd scripts
npm i @fontsource/space-grotesk @fontsource/jetbrains-mono @fontsource/noto-sans-jp
pip install fonttools brotli uharfbuzz
python3 gen_hero.py        # assets/hero.svg
python3 gen_sections.py    # headers, sub-labels, contact cards, languages
```

Things you may want to edit:

| What | Where |
|---|---|
| Name, role, chips, tag | `gen_hero.py`: search for `NAOKI`, `JUNIOR SOFTWARE`, `FULL-STACK`, `#NHashJP` |
| Launch timing (ignition, burn length) | `gen_hero.py`: `t0`, `DA`, `m` |
| Section titles | bottom of `gen_sections.py` (`header(...)`, `sublabel(...)`) |
| Contact cards | `card(...)` calls at the bottom of `gen_sections.py` |
| Languages, levels, orbit sizes | `bodies` list in `languages()` |
| Colours (accent = `ACCENT`) | top of `common.py` |

The telemetry readouts (ALT/VEL/PHASE) are computed from the rocket's actual path and
speed profile, so they stay in sync if you change the trajectory or timing.
